# Grand Duke Automotive premium website

## Scope
- Replace the placeholder with a complete, cinematic one-page automotive detailing website.
- Use a dark graphite, metallic silver, white, and restrained royal-blue visual system.
- Build responsive navigation, service and pricing showcases, process, benefits, gallery, testimonials, FAQ, quote form, and footer.
- Add refined motion, layered depth, glass effects, and mobile call/booking actions without hurting readability or speed.

## Experience
- Lead with a full-bleed luxury detailing image and direct booking actions.
- Preserve the supplied package names, vehicle pricing, services, and Grand Duke Automotive branding.
- Make pricing interactive with a vehicle-category selector.
- Add gallery filtering, testimonial controls, FAQ accordions, and a polished quote form.
- Use temporary “contact us” wording where phone, email, service area, or hours were not supplied rather than inventing details.

## Visual assets
- Generate a cohesive set of cinematic commercial automotive-detailing photographs for the hero, services, about, gallery, and key visual sections.
- Optimize and lazy-load non-critical imagery.

## Technical details
- Implement reusable React components within the existing TanStack Start structure.
- Define all colors, effects, and typography through semantic design tokens in the global stylesheet.
- Add accessible interactions, reduced-motion handling, semantic headings, image alt text, route metadata, and LocalBusiness/Service/FAQ structured data.
- Verify the finished page at desktop and mobile sizes, then resolve any layout, console, or build issues.
