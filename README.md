# Duke's Detail Drive

Create a completely new, premium, modern, pixel-perfect website for an automotive detailing and car care business.

IMPORTANT:

The current website shown in the reference image is outdated and should NOT simply be copied or slightly redesigned.

Use the uploaded current website screenshot and service/pricing image ONLY as reference for:

- Existing business information

- Services

- Service package names

- Pricing

- Existing visual assets

- General content

- Existing brand context

Create a significantly more premium, modern, cinematic, high-end website from scratch.

BUSINESS NAME:

Grand Duke Automotive

BUSINESS TYPE:

Premium Mobile Automotive Detailing & Auto Care Services

BRAND DIRECTION:

Grand Duke Automotive should feel like a luxury automotive detailing company serving premium vehicle owners.

The website should communicate:

- Luxury

- Precision

- Trust

- Professionalism

- Premium craftsmanship

- Automotive expertise

- Convenience

- Mobile service

- Attention to detail

DESIGN STYLE:

Create a premium 3D automotive website with a cinematic luxury aesthetic.

Think:

- High-end automotive showroom

- Luxury car commercial

- Premium detailing studio

- Dark cinematic environment

- Glossy automotive surfaces

- Subtle 3D depth

- Glassmorphism

- Soft reflections

- Dramatic lighting

- Premium typography

- Smooth animations

- Micro-interactions

- Depth and layering

DO NOT create a generic auto-detailing template.

The design should feel custom-built specifically for Grand Duke Automotive.

COLOR PALETTE:

Use a sophisticated luxury palette:

- Deep black

- Charcoal

- Dark graphite

- White

- Metallic silver

- Subtle royal blue accents

Use blue as an accent color rather than overwhelming the entire interface.

The overall appearance should be dark, luxurious, clean, and highly polished.

TYPOGRAPHY:

Use premium modern typography.

Headings:

Large, bold, elegant, automotive-inspired typography.

Body:

Clean, highly readable modern sans-serif.

Use strong typography hierarchy.

Avoid excessive fonts, decorative fonts, or cheap-looking typography.

GLOBAL UI:

- Rounded but sophisticated cards

- Thin borders

- Subtle shadows

- Glass effects where appropriate

- Metallic gradients

- Soft background glows

- High-quality automotive imagery

- Large visual sections

- Generous spacing

- Clean alignment

- Consistent grid system

- Pixel-perfect responsive layout

The website must look excellent on:

- Desktop

- Laptop

- Tablet

- Mobile

Use a proper responsive design rather than simply shrinking the desktop layout.
